# zz-modern-weapons

Seven modern weapons as dot-weapon catalogue rows, tuned from `cfg/addons/zz_modern_weapons/*.yml`, with a spawn-menu provider. On `zees-games`. Modelled on zee-dot-weapons, and carries its own minimal copy of that pack's view-model and netcode half (zee's classes name its own art table, and a pack may not require another optional addon; the generalisation is a nightly item, `zee-dot-weapons-1`). Read the family [CLAUDE.md](../../CLAUDE.md) first.

## Layout

| Path | What |
| --- | --- |
| `addons/zz_modern_weapons/zz_weapon_pack.gd` | `ZzWeaponPack`: the rows, built from a cfg table, durations in ticks at 64 Hz |
| `.../zz_weapon_config.gd` | `ZzWeaponConfig`: defaults, and the cfg directory layered over them (`DotAddonConfig.load_dir` by reflection when dot-core has it, else `DotYaml`) |
| `.../zz_weapon_art.gd` | `ZzWeaponArt`: the only file with a filename; placeholders until a glb is set in `TABLE` |
| `.../view/` | `ZzViewModel` (first person, bound to a `DotWeaponArsenal`'s signals), `ZzViewArms` (placeholder arms), `ZzWorldModel` (a watcher's view, fed by the replicated fields), `ZzWeaponPose` (draw, sway, recoil spring, reload and swing keys, aim), `ZzShotFx` (flash, tracer, impact), `ZzWeaponSound` (a hook, no audio shipped) |
| `.../net/` | `ZzWeaponNet` (four public fields, names shared with zee's so a bridge is pack-agnostic), `ZzFireTracker` (counts an arsenal's uses), `ZzFakeNet` (a stand-in for tests and renders) |
| `.../spawn_provider.gd` | `ZzSpawnProvider.spawn_entries()` for a host's spawn menu |
| `.../zz_def_export.gd`, `weapons/`, `provides.json` | the Workshop form, generated by `tools/export-defs.sh`; the suite fails when stale |
| `cfg/addons/zz_modern_weapons/default.yml` | the shipped example; must equal `ZzWeaponConfig.defaults()` (a suite check) |

## Rules

- A number lives in `ZzWeaponConfig.defaults()` and `default.yml`, never in a builder. Add a key to both; the suite compares them.
- A new weapon: id in `ZzWeaponIds`, defaults row, builder, art row, CREDITS.md row, then `tools/export-defs.sh`.
- Models: CC0 or CC-BY only, recorded in CREDITS.md (URL, author, licence). Never invent art; a placeholder stays labelled until a real model replaces it. Origin at the grip, muzzle toward -Z.
- Update `CHECKS` in `examples/zz_selftest.gd` when you add a check.
- Swapping a placeholder for a real glb changes `ZzWeaponArt.TABLE` only (`model`, and optionally `style` / a `view` override for hold, aim, support hand, kick). Motion is pose and placement: no assertion sees it, so run `tools/screenshot.sh --view <w>` and `--world <w>` (contact sheets) and look. Not headless; `GPU_OFFLOAD=0` when a box returns a blank frame.
- Presentation never touches the simulation; the view classes read the arsenal's signals and write nothing back.
- Screenshots (`tools/screenshot.sh`) after any art change.
